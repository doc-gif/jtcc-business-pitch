# 日本トレカセンター｜ファン向け二次流通ピッチ

5分の経営提案と、サービスの操作デモを兼ねるReactサイトです。販売・決済・データ送信はありません。表示される取引条件と収益試算は仮定であり、市場統計ではありません。

## 公開状況

GitHub Actionsによるデプロイ設定は済んでいます。初回デプロイ前にリポジトリ所有者が **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。設定後は `main` へのpushごとにビルドして自動デプロイします。静的サイト用のため別のホスティング契約や購入は不要です。

初回公開後のURL: https://doc-gif.github.io/jtcc-business-pitch/

## 画面

- 7枚の発表スライド。矢印キーで移動し、URLの `#slide-1` から `#slide-7` で直接開けます。
- 閲覧モード、補足・出典、印刷/PDF保存。
- コレクションの展示・希望受付と、持ち主の承認の違いを操作するモック。
- 購入者・取引頻度・金額・手数料率・費用を調整する試算。取引総額、手数料売上、費用控除後を別に表示します。

## FigmaとReactの対応

Figma Designは7枚のスライド構図と色・タイポグラフィを編集する元ファイルです。Reactはレスポンシブ表示、発表操作、モックの状態遷移、試算式、出典・印刷を担います。自動同期は設定していません。

| Figmaフレーム | Reactの内容 |
| --- | --- |
| 01 / Opening | 1枚目：提案の主張 |
| 02 / Problem | 2枚目：探すファンと譲れる所有者 |
| 03 / Choice | 3枚目：所有継続と譲渡の選択 |
| 04 / Demo | 4枚目：コレクションと任意の希望受付 |
| 05 / Model | 5枚目：取引額・手数料売上・費用試算 |
| 06 / Why JTCC | 6枚目：社内資産の活用可能性 |
| 07 / Validation | 7枚目：初期検証と判断ゲート |

### デザイン変更をアプリに反映する手順

1. Figmaで対応する `01`〜`07` フレームを編集します。フレーム名と順序は対応表に合わせます。
2. CodexにFigmaデザインのURLと「このデザインをReactに反映」と伝えます。
3. Figma MCPで変更箇所を読み取り、Reactの対応するスライド/CSSに反映します。操作・計算の挙動はコード側で保持します。
4. ビルドと表示を確認した後、GitHubに反映し、公開環境へデプロイします。

FigmaのCode Connectはコンポーネントとコードの対応を示す機能で、デザイン変更をアプリへ自動反映する同期ではありません。

## 開発

Node.js 20.19+ または 22.12+ を想定します。

```sh
pnpm install
pnpm dev
pnpm build
```

公開情報の位置づけと事業上の未決事項は、サイト内の「補足と確認事項」を参照してください。
